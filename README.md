# موقع شراكات ساق الجوري — saqaljori.sa

صفحة هبوط للشراكات (فنادق، جهات حكومية وشركات، مستشفيات، قاعات) بالعربية والإنجليزية، مع زر المتجر `shop.saqaljori.sa`.
الموقع يعمل على **GitHub Pages** (مجاناً)، ويُعدّل محتواه بالكامل من **Pages CMS** عبر `saqaljori.sa/admin`.

## محتويات المستودع

| الملف / المجلد | الوظيفة |
|---|---|
| `_data/content.yml` | كل نصوص الصفحة (عربي وإنجليزي) والأسعار والباقات |
| `_data/settings.yml` | الروابط، الأرقام، البريد، رمز النموذج، ملف العرض |
| `_layouts/landing.html` | تصميم الصفحة (لا يحتاج تعديلاً) |
| `assets/` | التنسيق والصور والخطوط والملفات المرفوعة |
| `.pages.yml` | إعدادات لوحة التحكم Pages CMS |
| `CNAME` | يربط الموقع بالدومين saqaljori.sa |
| `admin/` | يحوّل saqaljori.sa/admin إلى لوحة التحكم |

## 1) رفع الموقع على GitHub

1. أنشئوا حساباً أو منظمة على GitHub باسم ساق الجوري (يُفضّل منظمة، وأضيفوا المشرفين فيها).
2. **New repository** باسم مثل `saqaljori-site`، واجعلوه **Public** (GitHub Pages المجاني يعمل مع المستودعات العامة).
3. **Add file ← Upload files** ثم اسحبوا كل محتويات هذا المجلد.
   - ملف `.pages.yml` مخفي في بعض الأجهزة. إن لم يظهر بعد الرفع: **Add file ← Create new file**، سمّوه `.pages.yml` والصقوا محتواه.
4. **Settings ← Pages**: Source = `Deploy from a branch`، Branch = `main` و `/ (root)` ثم Save.
5. في نفس الصفحة: **Custom domain** = `saqaljori.sa` ثم Save. وبعد نجاح فحص DNS فعّلوا **Enforce HTTPS**.

## 2) ربط الدومين من لوحة مزود الدومين

ادخلوا إدارة سجلات DNS للدومين saqaljori.sa وأضيفوا:

| النوع | الاسم (Host) | القيمة |
|---|---|---|
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |
| AAAA (اختياري) | @ | 2606:50c0:8000::153 · 2606:50c0:8001::153 · 2606:50c0:8002::153 · 2606:50c0:8003::153 |
| CNAME | www | اسم-الحساب.github.io |

**مهم جداً:**
- لا تحذفوا سجل `shop` الخاص بسلة، ولا سجلات `MX` و `TXT` الخاصة ببريد info@saqaljori.sa.
- احذفوا فقط أي سجل `A` قديم للاسم `@` (مثل صفحة الحجز الافتراضية).
- التفعيل قد يستغرق حتى 24 ساعة.
- يُنصح بتوثيق الدومين في GitHub (إعدادات الحساب أو المنظمة ← Pages ← Add a domain) بإضافة سجل TXT الذي يعطيكم إياه، لحمايته من الاستيلاء.

## 3) تفعيل لوحة التحكم Pages CMS

1. افتحوا [app.pagescms.org](https://app.pagescms.org) وسجلوا الدخول بحساب GitHub.
2. ثبّتوا تطبيق Pages CMS على الحساب أو المنظمة المالكة للمستودع، واختاروا هذا المستودع فقط.
3. افتحوا المستودع: سيقرأ ملف `.pages.yml` وتظهر لكم قائمتان: **الإعدادات العامة** و **محتوى الصفحة**.
4. عدّلوا واضغطوا **Save**. كل حفظ يُنشر تلقائياً، ويظهر في الموقع خلال دقيقة أو دقيقتين.
5. الرابط المختصر للوحة: `saqaljori.sa/admin`.
6. لإضافة موظفين للتعديل: من إعدادات المستودع داخل Pages CMS (Collaborators) أو أضيفوهم في منظمة GitHub.

## 4) تفعيل نموذج الطلبات (Formspree)

1. سجلوا في [formspree.io](https://formspree.io) بالبريد info@saqaljori.sa وأنشئوا نموذجاً جديداً.
2. انسخوا رمز النموذج (الجزء الأخير من الرابط، مثل `xyzabcd`).
3. من لوحة التحكم ← **الإعدادات العامة** ← **رمز نموذج Formspree** والصقوه واحفظوا.
4. إذا تُرك الرمز فارغاً يختفي النموذج وتبقى أزرار واتساب والبريد تعمل.

## 5) ما يمكن تعديله من اللوحة

- كل النصوص بالعربي والإنجليزي، والأرقام، والجهات الأربع، والمنتجات وأسعارها، والباقات وأسعارها.
- الصور: صورة الواجهة، وصور الركائز والجهات والمنتجات (عند تركها فارغة تظهر بطاقات ملونة بأيقونات).
- إظهار أو إخفاء الأسعار، وملف العرض PDF، وشعارات العملاء وآراء الشركاء (تظهر تلقائياً عند إضافة أول عنصر).

**مقاسات الصور المقترحة:** الواجهة 1920×1080 · الجهات 1200×700 · الركائز 600×600 · المنتجات مربعة بخلفية فاتحة أو شفافة.
